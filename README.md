# 文明科技网络 · 地下天工殿

完整单人游戏入口为 `index.html`。运行 `npm run dev` 后打开提示的本地地址；由于 3D 使用 ES modules，请通过本地服务或部署后的网址游玩，不要直接双击 HTML 文件。

## 完整版玩法

- 四种文明起点：秦始皇、武则天、朱元璋、慈禧。时代初始能力不同，最终面对同一张文明科技网络。
- 真正的 3D 地宫、七座侧殿、八个独立实体部件。总装近景支持旋转、缩放和点选，制作完成后草图从墙面变成实体。
- 58 个科技节点横跨材料、制造、动力、能源、测量、控制、工业七大分支，形成交叉依赖。理论始终可见，玩家逐步获得制造能力。
- 五种手作加工：打磨、接合、旋转、对齐与平衡；提供空格键及辅助操作，减少操作门槛。
- 稳妥、省料、赶工三种常规方案，以及有明确风险提示的跨越前置试制。月份只随行动推进，不设实时倒计时。
- 侧殿升级、工坊事件、资源休整、四套系统验证与总装试验，形成从启封到结局的完整流程。
- 四类结局、工程记录、存档导入导出和结算卡保存。
- 旧版小木车、提水装置、自动敲铃器及自由工作台保留在“百工造物间”，沿用旧存档；完成小作品可为当前工程提供少量补给。

## 运行、验证与交付

`npm run dev` 启动本地服务；`npm test` 执行规则、控制器及实际 3D 几何检查；`npm run build` 生成 `dist/` 静态站点。

运行所需 Three.js 0.180.0、字体及美术素材均随站点提供，不依赖运行时 CDN。字体许可见 `assets/fonts/OFL.txt`，Three.js 许可见 `vendor/three/LICENSE`。

新版源码由 `palace-data.js`（数据、规则与存档）、`palace-models.mjs`（3D 几何与材质）、`palace-world.mjs`（场景与演出）、`palace-craft.mjs`（加工交互）、`palace.mjs`（界面流程）和 `palace.css` 组成。

39 项自动检查覆盖四时代通关、依赖关系、资源与事件、失败恢复、存档、旧版玩法，以及实体部件几何。控制器检查使用 DOM / 渲染器替身，未进行真实浏览器视觉、触屏或 GPU 帧率验收。

## 实现边界

这是可从开局玩到结局的单机浏览器版本。部件与建造空间使用真实三维程序几何；运动和制造能力使用游戏规则模拟，不是工程计算或刚体物理仿真。历史参考在游戏内“工程档案”列出，具体时代能力分级属于游戏设计推演。

新版进度存于当前浏览器、当前网址的 `tiangong-palace-v2`，旧版继续使用 `tiangong-workshop-v1`。两者互不覆盖；跨设备可手动导出、导入新版存档，尚无账户云同步。本地地址与线上地址各自保存进度。

# 保留模块：天工局 · 造物玩具箱

第一版可玩的民用机械造物游戏，现保留在 `workshop.html`，也可以从完整版的“百工造物间”进入。

## 当前玩法

- 三件造物：小木车、提水装置、自动敲铃器。
- 四种手作操作：移动打磨、点击敲钉、旋转对齐、绕圈缠绳。也可用空格或辅助按钮完成。
- 拖拽或点击拿取零件，放到工作台或点装配位置；点击已装的零件可以取下。
- 随时试运行、停机、撤回和收回全部零件。做过的零件之后直接取用。
- 大小轮混搭产生不同的动画结果和隐藏发现。
- 完成三件作品后解锁自由工作台，最多 18 件零件；相邻零件连接并传递运动，可以移动、移除和混搭。
- 九项科技自动点亮，作品进入陈列。音效可关闭，进度保存在当前浏览器。

## 文件

- `workshop.html` / `workshop.css`：界面与响应式布局。
- `game-data.js`：项目、零件、存档校验、完成判定与自由连接规则。
- `workshop.js`：手作交互、拼装、运动表现、音效与本地存档。
- `tests/`：规则测试，以及 DOM / Canvas 替身环境中的控制器流程测试。
- `legacy.html`：保留的旧冒险原型入口，继续使用原有样式与脚本。

## 验证和打包

`npm test` 运行规则及控制器流程检查。`npm run build` 将静态网页复制到 `dist/`。

控制器测试覆盖三项工程、四类加工、解锁、撤回、恢复与自由拼搭；使用 DOM / Canvas 替身，不等同于真实浏览器的视觉或触屏测试。

## 第一版边界

装置采用简化运动与连接规则，不是刚体物理仿真。自由工作台中距离不超过 150 个画布单位的零件视作连接，运动由摇柄、水轮或首个放置零件开始传递。存档只在当前浏览器和当前网址保留；本地试玩与线上试玩各自保存进度，不跨设备同步。

## 美术第二版：山岚造物

界面换为黛青、石绿、绢白、赭石、古金和朱砂配色；加入原创山间工坊庭院及阿巧头像，木制零件增加光照分面、木纹和玉色轮毂。美术定义与图像提示词见 `assets/ART-DIRECTION.md`。所有玩法、科技规则和本地存档键保留。

## 美术第三版：山野工坊

界面改成全屏工坊、边缘导航、底部零件栏与半透明加工面板。标题使用本地加载的 Noto Serif SC 700 子集字体；十二件零件使用原创透明材质图集，具有木纹、铜饰、雕刻与磨损细节。实时旋转和拼装锚点沿用既有玩法，素材未加载时仍可使用程序绘制的零件。存档键不变。
