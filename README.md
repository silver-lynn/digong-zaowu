# 地宫造物

[直接游玩](https://silver-lynn.github.io/digong-zaowu/) · [GitHub 项目](https://github.com/silver-lynn/digong-zaowu)

无需登录即可开始。四条时代故事、八种动手实验、自由 3D 工作台和收藏作品馆，统一采用中国古典青绿、赭金与朱砂的视觉风格。

新版入口为 `index.html`。开场使用精绘 **2D 御座**，镜头推近、下移，再接入真正的 3D 地下工坊。开场可以跳过，也可在设置中缩短。

## 本次完成

- 四条时代路线：秦始皇、武则天、朱元璋、慈禧。每条路线有八章各自的工坊叙述和按年代出现的事件；慈禧以皇太后身份出现。宫殿、人物和终局明确标为创作。
- 八类实验：共同基准、材料比较、结构拼合、水性胶彩拌合、传动取舍、机关顺序、湿度对照实验、团队分工交接。错误可就地修正，掌握经验之后不重复刷工序。
- 17 项经验分成木作、材料、动力、协同四条线，最终汇合。选材和颜色带入创作，带教决定会提供装配帮助，学徒整理记录的决定会影响最后的交接分工。
- 六位工匠，三次轻量的人事选择：用共同标准比较、师徒带教、保护学徒发言、独立复核、共同署名。
- 3D 自由工作台：七个机关起稿，实体部件、旋转、平移、升降、榫口吸附、联动连接、撤回、试运行及键盘替代操作。
- 云端作品馆：命名、作者署名、继续编辑、复制、备份导入导出、六个陈列位、分页收藏。陈列作品也进入地下主殿。
- 1600 × 2200 收藏海报由当前三维作品渲染生成，支持成器全貌与拆解视图，包含作者、时代与藏器印。

旧版地宫完整保留在 `palace-v2.html`，工匠小操作保留在 `workshop.html`，均可从设置进入。原有画像、美术和旧存档键保留。

## 保存与恢复

GitHub Pages 提供游戏页面，Sites Worker 与 D1 保存进度和作品。访客获得随机生成的 256 位身份密钥，浏览器仅保存这份身份及待同步草稿，正式档案在云端。服务器以密钥的 SHA-256 摘要隔离访客档案，公开页面不会共享同一个游客存档。密钥不进入网址、备份文件或公开仓库。跨域访问仅允许本项目所在的 GitHub Pages 域名，且不携带平台登录 Cookie。

继续使用同一浏览器即可找回访客档案；清除浏览器数据、使用无痕模式或换设备之前，请在设置中导出备份，再在新设备导入。原 Sites 地址仍兼容平台账号档案：优先使用平台转发的用户编号，邮箱兼容路径只保存摘要。每次写入检查版本，冲突时保留草稿；断线后可重试同步。访客档案与原账号档案不会自动合并，可通过导出、导入迁移。

四个时代各自保存。导入整册档案时，作品作为副本保留，已有时代进度不覆盖。旧版游戏继续使用原来的设备存档，原网址中的旧存档不会被删除。本地预览有独立的 SQLite 数据库，不与线上账号混用。

## 运行与验证

需要 Node.js 24。安装依赖后，`pnpm dev` 启动本地预览，`pnpm build` 构建前端和 Worker，`pnpm test` 运行检查。数据库变更通过 `pnpm db:generate` 生成迁移；生产迁移由 Sites 部署流程应用。

`pnpm build:pages` 生成 GitHub Pages 专用版本：将 `dist/client` 的全部内容（含 `.nojekyll`）发布到 `gh-pages` 分支，Pages 选择该分支根目录。模块和资源均使用相对路径，支持 `/digong-zaowu/` 子目录。`main` 保存完整源代码。云端服务地址由构建脚本写入 `runtime-config.mjs`；自行部署后端时需一并修改服务端允许的页面来源。GitHub Pages 本身不执行 Worker。

自动检查覆盖四条路线通关、八种实验、17 节点依赖、时代顺序、三维部件轴向、车轮与车台关系、连接与复制、旧版回归、控制器流程，以及真实 SQLite 上的账号/访客隔离、版本冲突、离线草稿恢复和公开访问路径。控制器使用 DOM 与渲染器替身；没有进行真实浏览器视觉、触屏或 GPU 帧率验收。

这是规则驱动的造物游戏。工作台运动是设计联动预览，不是刚体碰撞、承载或真实制造的工程验证。巡天器为架空的非操作性终局，不含现实武器制作、推进或制导方法。史实和科学出处可从游戏页脚查看。

## 源码与美术

`chronicle-data.mjs` / `era-stories.mjs` 保存路线和叙事，`lab-rules.mjs` / `chronicle-lab.mjs` 保存实验规则和交互；`chronicle-world.mjs` 负责主殿和镜头，`atelier-*` / `work-stage.mjs` 负责实体工作台；`archive-store.mjs` / `archive-request.mjs` / `server.mjs` / `db` 负责云端档案。

项目已统一改名为「地宫造物」。旧存储键和数据库表名保留，以免丢失已有档案；导入同时接受旧版与新版备份格式。

Three.js、字体和图像均随站点提供，运行时无需 CDN。字体许可见 `assets/fonts/OFL.txt`；Three.js 许可见 `vendor/three/LICENSE`。

开场主画面使用内置图像生成工具制作，源图 `assets/throne-opening-v3.png`，网页使用压缩版本 `assets/throne-opening-v3.webp`。提示词和使用方式记录在 `assets/OPENING-ART.md`。四位统治者原有画像全部沿用；地下场景和功能部件为真正的三维几何。
